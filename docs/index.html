Real screenshot with the demo event. The address 192.168.1.20 is an example.

This is the first public alpha (0.1.0, phase 1 of the plan). Crew Link has only been tested in demo mode on the test computer (one Mac) and with more than 100 automatic tests. The test with real phones and tablets is still to come; Windows and a real club night are not tested either. The app is not signed or notarized. Try it before an important night, keep a printed timetable, and tell us what you find on Discord.

Features

Everyone knows how long is left.

The lead builds the night on one computer in the show network – the control desk. Everyone else sees the part they need. Crew Link only shows times: it never stops the music and never switches the light.

Timetable with days and floors

One night or a festival with several days, each with opening hours and its own curfew. Slots on a timeline or as a list, Copy day, templates, A4 print.

Countdowns that do not jump

Set end, next slot, floor end and curfew. Green, from 10 min yellow, from 2 min red, then red with “+” when a DJ runs over.

Phones without an app

Connect phones shows one QR code per role: lead, booth, DJ, tech, security, bar. Each role sees what it needs.

One house clock

The control desk gives the time. Browsers measure their offset, so a phone with a wrong clock still counts right – about ±0.01 s on the test computer.

Big clock for booth and DJ desk

Full screen, one floor: countdown, who comes next and a bar to curfew. As a window on the control desk or in the browser.

Public page for the entrance

“Now · next” per floor, with public names only. A secret guest stays “Special Guest”.

Keeps counting without network

If the Wi-Fi drops, phones and clocks keep counting with the last plan and show a yellow strip.

Running over? You decide

Shorten next and Shift everything show a preview first. Crew Link never changes the plan by itself and warns before curfew.

Suite chat with EMERGENCY

On the control desk Crew Link is a member of the suite chat with LJ Link, LJL Link and VJ-Link. EMERGENCY is not a safety system.

How it works

One control desk, many screens.

Crew Link runs on one computer in the show network. Phones, tablets and screens open its pages in the browser. Everything stays in the local network: no account, no cloud, no telemetry, no connection to the internet.

Download

Download with the Link-Suite launcher.

All programs of the suite are downloaded, installed and updated with one launcher: Link-Suite, for Mac and Windows.

macOS · Apple siliconLink-Suite-macos-arm64.dmg macOS · IntelLink-Suite-macos-intel.dmg WindowsLink-Suite-windows.exe

About the launcher →

  1. Download the launcher for your computer and open it.
  2. Click Install next to Crew Link. The launcher downloads Crew Link from its GitHub releases, checks the file and keeps it up to date.
  3. Start Crew Link and open the demo.

If the launcher still shows Crew Link as coming soon, release 0.1.0 is not out yet – until then start it from the source code (below).

Single installers of Crew Link (Crew-Link-macos-arm64.dmg, Crew-Link-macos-intel.dmg, Crew-Link-windows.exe) and SHA256SUMS are in the GitHub releases of Crew Link.

Not signed or notarized yet. The launcher and Crew Link 0.1.0 are an alpha without a signature, so both systems may warn on the first start.

macOS (“Not Opened”): click Done, open System Settings → Privacy & Security, click Open Anyway and confirm with your password. Allow access to the local network when macOS asks.

Windows (“Windows protected your PC”): click More info, then Run anyway. When the firewall asks, allow Private networks, otherwise phones cannot reach the web interface.

Only do this for files from the official GitHub pages or this website.

Build from source

Build from source.

For developers, or as long as the launcher does not list Crew Link yet. You need Node.js 22 or newer and a Mac (Windows is planned but not tested).

git clone https://github.com/skyplayser/Crew-Link.git
cd Crew-Link
npm install
npm start -- --demo   # demo: 2 days, 3 floors
  1. Look around in the demo. It saves nothing: a set is running on Main, a DJ runs over in the Keller, curfew is in about two hours.
  2. Connect phones. The start screen shows the address and a QR code; ROLES has one per role. Phones must be in the same network.
  3. Your own night. New event: days, opening hours, curfew, floors – then drag slots into the timeline.
  4. On the night: tab NOW for the control desk, Big clock for a second screen.

All start options, the structure and the technical notes are in the README on GitHub.

Security

Show network only.

  • No PIN in 0.1.0. Anyone who reaches port 8070 can open every role, including the lead's page with internal names and notes. Switch on the web interface only in the show network or a separate crew Wi-Fi with a password – never in the guest Wi-Fi.
  • Off by default. The web interface is only on when the lead chooses Connect phones.
  • Unencrypted, no HTTPS – like Art-Net, OSC and the suite chat.
  • The web server only accepts GET/HEAD, checks host and origin and its pages load nothing from outside. If port 8070 is taken, Crew Link says so and keeps the port, so printed QR codes stay valid.

The curfew in Crew Link is the time you enter. Crew Link does not know or check permits, conditions or legal closing times – the organiser stays responsible for them.

EMERGENCY and Crew Link are not an alarm or safety system. They do not replace announcements, radios, the fire alarm or the event's safety plan. Messages can get lost or arrive late, and anyone in the same network can send them. Software, networks and devices can fail – keep the printed timetable on the wall.

Part of the Link-Suite

Free programs for event technology that listen instead of control, need no server and stay in the local network. They share the suite chat, EMERGENCY and the same words: show network, booth, suite chat.

LJ LinkShows the lighting jockey what the DJ plays – decks, waveforms, cues, BPM from Pioneer and Denon – and sends the tempo to the light desk.
LJL LinkBrings the Serato decks of the DJ's Mac into LJ Link, straight from the club's USB stick.
VJ-LinkLive visuals run by the light desk, on screens, LED walls and projectors.
